Shortcuts now expand in TinyMCE editors in classic (iframe) mode.

Import and export fixes:
- Import merges by shortcut. Existing shortcuts get the new value, new ones are added, and nothing is deleted. Importing the same file twice no longer duplicates rows.
- An invalid file is rejected as a whole and your list stays as it was.
- Values expand exactly as written. Text with percent escapes like a%20b is no longer decoded.
- Shortcuts named after built-in words such as "toString" or "constructor" now expand correctly.
